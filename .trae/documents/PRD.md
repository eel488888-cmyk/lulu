# 王鹭芳个人作品集网站 - 产品需求文档（PRD）

## 1. 产品概述

- 为内容创作者王鹭芳打造一款单页个人作品集网站，以视频交互为核心叙事手段，展示其在内容策划、AI 工具运用、账号运营等方面的能力与经历。
- 目标用户为潜在合作方、HR、品牌方与同行创作者；产品价值在于通过沉浸式视频交互与精致动效，在 30 秒内建立鲜明、专业且活泼的个人品牌印象。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客 | 无需注册 | 浏览首页视频交互、查看各板块内容、访问子页面占位、下载简历 PDF、复制联系方式 |
| 站主（隐式） | 后台维护 | 通过源码更新内容、替换视频与图片资源 |

### 2.2 功能模块

1. **首页（/）**：小猫开场视频 → 主视频背景 + 打字标题 + 顶部导航栏 → 定格图片热区彩蛋视频
2. **关于我板块**：自我介绍标题 + 擅长/工具药丸标签 + 四张跳转卡片（2x2 网格）
3. **技能板块**：五个带填充动画的进度条
4. **联系方式板块**：浅珊瑚粉背景 + 可复制邮箱/手机 + 社交图标 + 下载简历按钮 + 结尾标语
5. **子页面**：/account、/project、/internship、/campus，均显示"详情页即将上线"占位并保留导航栏

## 3. 核心流程

**主流程**：访客打开网站 → 观看小猫开场视频 → 点击小猫触发主视频播放 → 观看主视频期间标题逐字出现、导航栏滑入 → 主视频结束定格为图片 → 鼠标移入右侧热区看到"点击我"标签 → 点击触发彩蛋视频 → 彩蛋结束回到定格图片 → 向下滚动浏览关于我/技能/联系方式 → 点击卡片进入对应子页面占位 → 通过导航栏返回首页。

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：色彩鲜明、活泼可爱，带有丰富但流畅的微交互和滚动动画。整体偏暖色调，珊瑚粉为主点缀色，配合奶油白与深炭灰底色形成对比。
- **主色**：珊瑚粉 `#FF6B7A`（点缀/强调）、奶油白 `#FFF8F3`（背景）、深炭灰 `#2A2A2A`（文字/视频遮罩）
- **次色**：薄荷绿 `#7FD8BE`（技能条）、暖黄 `#FFD166`（标签强调）、雾灰 `#E8E8EC`（工具药丸）
- **按钮风格**：药丸按钮（圆角 999px），主按钮带柔和阴影；卡片白底圆角 16px、轻微阴影、hover 上浮 6px + 珊瑚粉边框
- **字体**：标题用衬线体（Noto Serif SC / Playfair Display）凸显个人气质；正文用圆体（Quicksand / Noto Sans SC）保持活泼可爱感；打字标题 60px 加粗
- **布局风格**：首屏全屏视频沉浸式，下方板块单列纵向滚动 + 卡片 2x2 网格；顶部固定磨砂导航栏
- **图标/emoji 风格**：使用 emoji 作为板块视觉锚点（✨🛠️📱🎯💼🎓💡☕），社交图标用线性 SVG

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素（样式/布局/颜色/字体/动画） |
|----------|----------|-------------------------------------|
| 首页 | 开场遮罩 | 全屏 `rgba(0,0,0,0.85)` 黑遮罩；中央 cat.mp4；下方白色圆体 20px"点击小猫"文字，呼吸闪烁 + 上下浮动动画 |
| 首页 | 主视频背景 | 全屏 main.mp4 object-fit:cover；左侧绝对定位文字区，"王鹭芳"60px 白色加粗衬线、"Portfolio 作品集"24px 白色字间距 3px；逐字 80ms 打字效果 + 末尾光标闪烁 |
| 首页 | 顶部导航栏 | fixed 顶部，半透明磨砂 `backdrop-filter: blur(12px)`，初始透明从上滑入；滚动超过视频高度后背景加深；移动端转汉堡菜单 |

| 首页 | 技能 | 浅灰背景，五个进度条：轨道雾灰、填充珊瑚粉渐变；进入视口从左到右 1.2s 填充 |
| 首页 | 联系方式 | 浅珊瑚粉 `#FFE4E1` 背景，居中布局；邮箱/手机可点击复制带 toast 提示；社交图标 hover 放大；下载简历按钮珊瑚粉实心；底部标语含 ☕ emoji |
| 子页面 | 占位页 | 居中"详情页即将上线"衬线体 32px 灰色；保留顶部导航栏可点击返回首页 |

### 4.3 响应式

- **桌面优先**：默认设计 1280px+ 桌面布局，2x2 卡片网格、横向导航栏、视频全屏背景
- **移动端自适应**：≤768px 时导航栏转汉堡菜单（下拉展开）；卡片自动堆叠为单列；板块内边距收窄；视频标题字号缩小（"王鹭芳" 36px、"Portfolio 作品集" 16px）；热区范围保持右侧 30%
- **触摸优化**：彩蛋热区点击响应 touch 事件；复制按钮在移动端调用 Clipboard API 并提供 toast 反馈；导航项点击区域 ≥44px

### 4.4 3D 场景指引

- 不适用（本项目无 3D 场景）
